# Relógio Digital

Um projeto simples de **Relógio Digital** desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de praticar lógica de programação, manipulação do DOM e atualização dinâmica de dados em tempo real.

👉 **Acesse o projeto online:**  
🔗 https://gutosavi.github.io/relogio-digital/

---

## Objetivo do Projeto

Este projeto foi criado com foco em:

- Treinar **JavaScript básico**
- Trabalhar com **datas e horas**
- Utilizar `setInterval` para atualização em tempo real
- Manipular elementos do **DOM**
- Consolidar conceitos fundamentais de Front-end

## Funcionalidades

- Exibição da hora atual em tempo real
- Atualização automática dos segundos
- Layout simples e responsivo
- Deploy automático via GitHub Pages

---

## Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

- Uso do objeto `Date`
- Formatação de horas, minutos e segundos
- Atualização contínua com `setInterval`
- Organização básica de código JavaScript
- Separação de responsabilidades entre HTML, CSS e JS
- Responsividade com Media Query
